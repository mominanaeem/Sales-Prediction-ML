**Sales Prediction using Machine Learning**


This is my first self-directed data science project, created to understand how advertising budgets (TV, Radio, Newspaper) impact product sales.

Project Workflow:
- Used Pandas to load the data and handle basic cleaning.
- Created visualizations with Matplotlib to explore the relationship between TV ads and sales.
- Trained a Linear Regression model with Scikit-Learn to predict sales outcomes.
- Evaluated the model using an 80/20 train-test split, reaching an R-squared accuracy of 0.90 (90%).
